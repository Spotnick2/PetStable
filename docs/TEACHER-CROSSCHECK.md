# Teacher cross-check

Generated by `Tools/import-teachers.py`; do not hand edit. Issue #31.

**Agreement between sources never verifies anything.** Every shipped teacher claim is reference status; only in-game evidence (a probe or a sighting) can confirm one.

Reviewed 2026-11-16 against client build 1.60.1.70938. Inputs: petopia ability: observation 1, content 1; petopia rank: observation 1, content 1; petopia teacher: observation 1, content 1; petopia look_creature: observation 1, content 1; beastmaster creature: observation 3, content 2. The October inventory supplies the catalog creatures.

- **Candidates** come only from Petopia's abilities listing (teacher rows). Petopia's look pages, Beastmaster, the October inventory and the client tables only cross-check them.
- **Client data limits:** the client's CreatureFamily table checks the family names, not which family a given creature belongs to. Client spell levels check rank levels, not creature levels or places. The client has no creature table for names, levels or zones, so those have no client comparison.
- **How values compare:** names exactly; levels as ranges ("11Rare" is 11; "Boss" counts as missing); zones agree when every source shares one name, each part of "Subzone, Zone" or a list counting as a name, and "X (Dungeon)" also as X; families by letters and digits, Beastmaster's "owl" being Bird of Prey; Beastmaster's "Screech" being Demoralizing Screech; coordinates when the inventory's map name is a Beastmaster zone and any pair of points is within 3 map units. Inventory claims are compared one by one, each with its source.
